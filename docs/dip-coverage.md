# Digital Image Processing source and coverage map

The 46 DIP questions in `data/dip.js` are newly written study prompts and answers. They use the supplied material as reference without reproducing examination text as an app asset. The module outline defines the ten-week structure. The study book supplies terminology, worked examples and application context. Scanned papers were visually reviewed; source labels in the bank identify the exam topics that informed each prompt.

| Supplied material | Topics reflected in the bank |
| --- | --- |
| `DIGITAL IMAGE PROCESSING MODULE OUTLINE (1).pdf` | Weeks 1–10, from pixels and digitization through restoration, CNNs and applications |
| `DIP_Study_Book_Module1.docx` | Definitions, spatial/frequency processing, convolution, segmentation, compression, restoration, classification and ethics |
| `HCSCI239_APR_2025.pdf` | Image definition, enhancement, restoration, resolution/aspect ratio, compression and applications |
| `HCSCI239_JUN_2026.pdf` | Pixels/bit depth/formats, histogram and edges, ethics, restoration, morphology and CNNs |
| `HCSCI239_NOV_2025.pdf` | Processing pipeline, image creation, spatial versus frequency methods, histogram, segmentation and edge operators |
| `HSVG341_NOV_2024.pdf` | Formats, image subtraction, NIR:red ratio, spatial frequency, Sobel calculation and confusion-matrix accuracy |
| `HSVG528_JUN_2025.pdf` | Geometric/radiometric correction, image subtraction, NIR:red ratio, Sobel calculation and supervised classification |
| `Mophological Image Processing.pptx` | Dilation, erosion and structuring-element examples |
| `Morphological_Image_Processing.pptx` | Opening, closing, boundaries and morphology applications |
| `Morphological_Image_Processing-2.pptx` | Morphological combinations, noise cleanup and shape analysis |

The HSVG papers include remote-sensing examples that extend beyond the HCSCI239 outline. They are included as applied questions in the relevant weeks. The near-infrared:red **ratio** is kept distinct from NDVI. The Sobel exercise states its sign convention; edge magnitude needs both directional responses.

Every question has three authored answer depths. `easy` explains the core idea plainly, `medium` adds a practical example, and `hard` adds a technical limitation or tradeoff. Question difficulty describes the prompt; answer depth describes the model answer shown to the student.

Visuals in `assets/visuals/` were downloaded from Wikimedia Commons only after checking the individual file's license metadata. `manifest.json` records its author, license and source page. The app also draws original process diagrams and provides a canvas for annotations. Downloaded works are used as supplied, with attribution next to each shown image; no source exam or slide artwork is redistributed.
